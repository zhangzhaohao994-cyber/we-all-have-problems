# 我们都有问题 · 网页试玩

这是仍在制作中的 2D 叙事游戏。三段生活主线、九条支线，以及不同选择带来的后续场面。

手机或电脑浏览器打开本站首页即可游玩。手机竖屏和横屏均可操作，阅读舒适度可在“声音 / 设置”调整；建议使用近期版本的 Safari、Chrome 或 Edge。首次进入请点“开始”或“继续”，浏览器需要这次点击来开启声音。

进度保存在当前浏览器中。换手机、电脑或浏览器之前，在“保存 / 读取”选择“导出进度”，保存 JSON；在另一台设备的同一菜单导入。隐私浏览模式、清理浏览器数据或禁止存储可能影响自动保存，导出文件可用于恢复。浏览器之间不会自动同步。

网页需联网载入画面与声音，声音按当前场景需要下载。制作中版本的最终听感、全部结局和实体设备验收仍未完成。

制作名单和完整许可见 [制作名单](制作名单.html)。这个仓库只含运行游戏及必要许可。

维护者可在 GitHub 仓库 Settings → Pages 中选择 Deploy from a branch，分支 main，目录 / (root)。仓库根目录保留 `.nojekyll`；不需要 GitHub Actions 工作流。
